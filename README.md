## Research

I study multi-agent LLM systems -- specifically, how communication between language model agents affects their outputs. My core finding is that agent communication simultaneously creates strategy consensus and calibration contagion, and that evaluation has an "impossibility triangle" (bias, reliability, and coupling cannot all be optimized at once).
